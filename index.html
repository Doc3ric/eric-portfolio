AI Job Hunter — Resume-to-Job Match Analyzer

A full-stack AI-powered job matching tool split into a Next.js web app and a Chrome Extension. The extension injects a side panel into job listing pages (e.g. OnlineJobs.ph), scrapes the job description, and sends it alongside your stored resume to the Next.js API — which runs it through Groq LLaMA 3.3 70B (with a Gemini fallback) to return an ATS match score, matched/missing skills, and improvement recommendations.
